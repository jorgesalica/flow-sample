# @flows/shared

Shared TypeScript interfaces and types used across all Flow packages.

## Exports

- **Track, Artist, Album** — Spotify domain models
- **Lyrics, LyricsStatus, LyricsStats** — Lyrics domain models
- **SearchOptions, PaginatedResult** — Query/pagination types
- **GenreCount, YearCount** — Aggregation types
- **StatusTone, StatusMessage** — UI status types

## Usage

```ts
import type { Track, Artist, Lyrics } from '@flows/shared';
```
