# Lyrics Flow: Before & After

> **Purpose**: This document contrasts the scattered experience of searching for lyrics *before* the system, and the integrated, persistent experience *after* its intervention.

---

## 1. The Fragmented Search (Before)

*Without system intervention. The Consciousness and the scattered web.*

*   **The Impulse**: A song plays. A line resonates. The Consciousness wants to see the full text — to read what they've been singing for years without truly hearing.
*   **The Hunt**: A browser opens. A search begins. "Song name + lyrics". The results: ad-infested sites, incorrect transcriptions, missing verses. The signal drowns in noise.
*   **The Ephemeral Victory**: Eventually, the lyrics appear. They're read, felt, and then... closed. The tab disappears. The moment passes. Next time, the hunt repeats.
*   **The Disconnection**: The lyrics live "out there" — never connected to the track, never persistent, never sovereign.

---

## 2. The Integrated Flow (After)

*The intervention of `lyrics-flow`. The Connector.*

*   **The Presence (Available)**: Each track in the collection now has a door — a button that whispers "lyrics available". The Consciousness knows: the text is within reach.
*   **The Summon (Fetch)**: With a click, the system reaches out to LrcLib. It sends the track's identity: title, artist, album, duration. It asks: "Do you have the words?"
*   **The Crystallization (Persist)**: If found, the lyrics are stored locally — crystallized alongside the track. They become part of the collection, not a visitor from the web.
*   **The Absence (Not Found)**: If no lyrics exist, the system marks the track honestly. "No lyrics found." No endless retries, no false hope. Clarity over illusion.
*   **The Reading (View)**: The Consciousness opens the lyrics and reads. Title, artists, album — all present. The words finally have a home.

---

## 3. The Batch Harvest (Optional)

*For those who want everything at once.*

*   **The Command**: A single button — "Fetch All Lyrics" — triggers a sweep across the entire collection.
*   **The Patience**: Track by track, the system queries LrcLib. Some return with words, others with silence.
*   **The Result**: When it ends, the collection is complete. Every track is either enriched with lyrics or marked as unreachable. The hunt is over.
