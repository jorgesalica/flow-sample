3. [Cascade Agent](iterations/it3-cascade-agent.md): patterns, risk context, and directional
   bias across analysis layers.
4. [Cascade Wizard](iterations/it4-cascade-wizard.md): guided top-down timeframes and
   context propagation from macro to micro.
